# HTML and CSS Projects

This repository contains all of the coding projects I built throughout my HTML and CSS course at The Tech Academy. As I worked through the course I pushed my code here from my local machine to GitHub, so this repo tracks my progress and acts as part of my online portfolio.

🔗 **Portfolio website:** https://latifzidan-art.github.io/Portfolio/

## Projects

Each project below has a live demo (hosted with GitHub Pages) and its source code in this repo.

### 1. Photography One-Page Website
My first one-page website. It has a home section, an image gallery, embedded YouTube videos, a contact form, a footer, and a navigation bar that jumps to each section using HTML bookmarks.
- **Live demo:** https://latifzidan-art.github.io/HTML-and-CSS-Projects/One-Page%20Website/one_page_website.html
- **Code:** [One-Page Website](One-Page%20Website)

### 2. The Pet Shop Website
A multi-page website for a pet shop, with a home page, an "Our Pets" page (including a price table), and a contact page. The pages are linked together with a navigation bar.
- **Live demo:** https://latifzidan-art.github.io/HTML-and-CSS-Projects/The-Pet-Shop-Website/
- **Code:** [The-Pet-Shop-Website](The-Pet-Shop-Website)

### 3. Creating CSS Effects
A practice page where I tried out different CSS effects: box and text shadows, rounded corners, gradients, opacity, hover transitions, transforms (rotate/scale/skew), image filters, and a keyframe animation. Uses an external stylesheet.
- **Live demo:** https://latifzidan-art.github.io/HTML-and-CSS-Projects/creating-css-effects/
- **Code:** [creating-css-effects](creating-css-effects)

### 4. Simple Recipes
A recipe website with four dishes, each with a photo, an ingredients list, and step-by-step instructions. It also includes an About section I added myself.
- **Live demo:** https://latifzidan-art.github.io/HTML-and-CSS-Projects/Simple-Recipes/
- **Code:** [Simple-Recipes](Simple-Recipes)

### 5. Academy Cinemas (Bootstrap)
A movie theatre website built with the Bootstrap framework. It has a responsive navbar, a hero section, a grid of movie cards, a booking form, and a footer built with Bootstrap.
- **Live demo:** https://latifzidan-art.github.io/HTML-and-CSS-Projects/Academy-Cinemas/
- **Code:** [Academy-Cinemas](Academy-Cinemas)
